# 扩展接口

本项目的核心固件只保证前进、后退和抬腿动作。下表记录 PCB 上可见、但需要用户自行完成驱动和电气验证的扩展方向。

## 超声波 HC-SR04

原理图预留 `TRIG` 和 `ECHO` 网络，候选引脚为 PB10/PB11；但当前固件没有 HC-SR04 驱动。另有历史 `BOO` 模块可能占用 PB11，因此启用超声波前必须先确认复用关系并关闭冲突外设。

HC-SR04 的 Echo 常见为 5 V 电平，不能未经确认直接接入 STM32 GPIO。请使用分压或合适的电平转换，并以所用模块数据手册为准。

建议的软件集成方式：

1. 用定时器输入捕获或可靠的非阻塞计时测量 Echo 高电平宽度。
2. 在约 25 ms 的主循环节拍中更新距离状态，不要用长时间阻塞延时。
3. 在进入前进状态机前增加“距离低于阈值则停止/复位”的安全门。
4. 先在断开舵机负载的情况下验证 GPIO、电平和时序，再接入整机。

## 其他可扩展方向

- 预留接口可用于传感器、电源监测或自定义串口设备，但必须重新核对原理图、GPIO 复用、5 V/3.3 V 电平和中断占用。
- 舵机角度表、步态节拍、抬腿幅度和左右 Trim 位于 `User/main.c` 的参数区；修改后应先架空测试。
- 新增蓝牙指令时建议使用完整命令匹配，避免历史前缀匹配造成误触发。
