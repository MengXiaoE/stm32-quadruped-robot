# 蓝牙控制

## 连接

1. 给机器人上电，并确认 HC-05 与主控共地。
2. 手机打开蓝牙权限，搜索 HC-05。
3. 第一次配对时按模块实际密码操作；常见默认值是 `1234`，但不同模块可能不同。
4. 在兼容的串口蓝牙控制器中编辑按钮内容，发送下面的完整帧。

固件默认 USART1 为 9600 8N1：PA9 为 TX，PA10 为 RX。每条指令都必须包含 `@` 起始符、`#*` 结束符。

## 核心指令

| 动作 | 发送内容 |
| --- | --- |
| 前进 | `@UP#*` |
| 后退 | `@BACK#*` |
| 抬腿/恢复站立 | `@TJ#*` |
| 停止并回到复位姿态 | `@REST#*` |

工程源码还包含其他历史动作命令，但本 README 只承诺上述核心动作。若要扩展协议，请保持帧边界并在主循环中增加明确的状态机分支。

## 供电安全

舵机电流不应由 USB 或调试器单独承担。外部舵机电源、主控 GND、HC-05 GND 必须共地；第一次测试时把四足架空，确认舵机不会撞机械限位。
